# Fragmentos da Ordem

MVP de um jogo de Sudoku narrativo e altamente visual.

## O que está incluído

- Sudoku 9 × 9 funcional.
- Seleção contextual de linha, coluna e bloco.
- Modo de anotações.
- Sistema de pistas e erros.
- Personagem-guia e narrativa reativa.
- Cenário que evolui conforme o progresso.
- Layout responsivo para desktop e mobile.

## Executar localmente

Abra o arquivo `index.html` diretamente no navegador.

## Build de produção

```bash
npm run build
```
